# Getting Support

Choose the right channel so questions can be handled efficiently.

| Need | Where to go |
|---|---|
| Bug report | [GitHub Issues](https://github.com/abx15/trifusiondynamics/issues) |
| Feature proposal | [GitHub Discussions](https://github.com/abx15/trifusiondynamics/discussions) |
| Usage and setup questions | [GitHub Discussions](https://github.com/abx15/trifusiondynamics/discussions) |
| Security vulnerability | [Private process in SECURITY.md](SECURITY.md) |
| Commercial project or integration | [TriFusion Dynamics contact page](https://trifusiondynamics.vercel.app/contact) |
| Services | [Services catalogue](https://trifusiondynamics.vercel.app/services) |

Before asking, search the README, documentation and existing issues. Include your operating system, relevant runtime versions, exact command, sanitized logs and a minimal reproduction. Never post secrets, tokens, database URLs or customer data.

This is an actively evolving project; community support is best-effort and no response-time SLA is currently offered.
