# Shared Assets

This directory contains shared assets used across multiple applications in the AgencyOS project.

## Structure

- `logos/` - Logo files and brand assets
- `icons/` - Icon files (to be added)
- `images/` - General image assets (to be added)

## Usage

These assets can be referenced from any app using relative paths or imported as needed.

## Guidelines

- Use descriptive filenames
- Keep file sizes optimized for web
- Include multiple formats (PNG, SVG) when appropriate
